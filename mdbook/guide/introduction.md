# Introduction

User-facing guide for this project, built with [mdBook](https://rust-lang.github.io/mdBook/).

- Narrative docs (how to use / operate the project) live here under `docs/guide/`.
- API docs are generated separately by `cargo doc`.
- Architecture decisions live under `docs/architecture/` and are managed by `dg`
  (DecisionGraph) — see `AGENTS.md`.

Run `mdbook serve mdbook` to preview locally.
